# Berlioz Conseil — Carte SEO / GEO / LLM SEO

## Principes

Le SEO doit rester propre, sobre et conforme.

Objectifs :

- améliorer la compréhension du site par Google et les moteurs IA ;
- ancrer le cabinet dans son territoire naturel : Rhône-Alpes, Lyon, Collonges-au-Mont-d’Or ;
- éviter le bourrage de mots-clés ;
- éviter les promesses réglementairement sensibles ;
- ne pas créer de pages locales artificielles en V1.

## Recommandations GEO / LLM SEO

Pour aider les moteurs IA à comprendre le site :

- écrire des phrases explicites ;
- nommer Berlioz Conseil, Aurélien Picard, Rhône-Alpes, Lyon, Collonges-au-Mont-d’Or ;
- structurer les pages avec des H2 clairs ;
- éviter les slogans vides ;
- rendre les statuts réglementaires vérifiables ;
- maintenir un `llms.txt` si déjà présent ;
- garder des contenus cohérents entre pages, footer, mentions légales et cadre réglementaire.

## Ne pas créer en V1

- pages locales artificielles “gestion de patrimoine Lyon 1”, “gestion de patrimoine Lyon 2”, etc. ;
- blog fiscal sans validation réglementaire ;
- pages partenaires ;
- cas clients ;
- comparateurs de placements ;
- simulateurs financiers.
