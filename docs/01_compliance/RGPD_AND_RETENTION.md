# Berlioz Conseil — RGPD et durées de conservation

## Rôle de ce document

Ce document distingue les données collectées via le site vitrine et les données traitées dans le cadre d’une relation contractuelle client.

Il doit servir de base à la page Confidentialité et aux mentions du formulaire de contact.

## Données collectées via le formulaire de contact

Champs actuellement souhaités ou compatibles avec le questionnaire :

- Prénom ;
- Nom ;
- Email ;
- Téléphone ;
- Ville ;
- Situation professionnelle ;
- Objet de la demande ;
- Message libre ;
- Préférence de contact ;
- Créneau souhaité ;
- Consentement RGPD ;
- Champ anti-spam technique de type honeypot.

## Finalité du formulaire

Finalité recommandée :

> Répondre à une demande de contact, organiser un premier échange patrimonial et, le cas échéant, préparer une demande d’audit patrimonial.

Ne pas laisser croire que le formulaire permet de recevoir un conseil patrimonial personnalisé.

Formulation à intégrer autour du formulaire :

> Aucun conseil personnalisé n’est délivré via ce formulaire.

## Responsable de traitement

Le document d’entrée indique que les données sont collectées et traitées par M. Aurélien PICARD en qualité de responsable de traitement.

Formulation site à valider :

> Les données collectées via le site sont traitées par Berlioz Conseil, représentée par Aurélien PICARD, en qualité de responsable de traitement.

Pour le site public, l’adresse recommandée est :

**contact@berliozconseil.fr**

**aurelien.picard@berliozconseil.fr**

## Base légale

À valider juridiquement selon la politique de confidentialité finale.

Pistes possibles :

- consentement pour la prise de contact via formulaire ;
- intérêt légitime pour le traitement de demandes entrantes ;
- nécessité précontractuelle si la demande vise un premier échange pouvant conduire à une mission.

Recommandation rédactionnelle : rester simple et ne pas sur-juridiciser la page.

## Durée de conservation — prospects / formulaire

Pour les simples demandes de contact ou prospects :

- conservation recommandée : 3 ans à compter du dernier contact actif du prospect ;
- suppression ou anonymisation à l’issue, sauf obligation légale contraire ou contentieux.

Point de prudence :

Ne pas appliquer automatiquement la durée de 5 ans du document d’entrée à tous les simples prospects.

## Durée de conservation — clients / relation contractuelle

Le document d’entrée indique :

- conservation pendant toute la durée de la relation contractuelle ;
- puis archivage pendant un délai de cinq ans ;
- sauf délais plus courts ou plus longs spécialement prévus, notamment en cas de litige.

Formulation possible :

> Les données collectées dans le cadre d’une relation contractuelle sont conservées pendant la durée de cette relation, puis archivées pendant cinq ans, sauf obligation légale spécifique ou durée différente requise notamment en cas de litige.

## Droits des personnes

Le document d’entrée mentionne les droits suivants :

- accès ;
- rectification ;
- limitation ;
- opposition ;
- portabilité.

La page Confidentialité peut également mentionner l’effacement lorsque applicable, avec prudence selon obligations réglementaires.

## Réclamation CNIL

Formulation recommandée :

> Si vous estimez, après nous avoir contactés, que vos droits Informatique et Libertés ne sont pas respectés, vous pouvez adresser une réclamation à la CNIL.

## Données de proches

Le document d’entrée précise que, concernant les proches du client, le client est invité à les tenir informés des modalités de traitement de leurs données personnelles.

Cette mention concerne surtout la relation contractuelle, pas le formulaire public.

## Services tiers

### Formspree

Le formulaire utilise Formspree pour transmettre les demandes.

À documenter dans la politique de confidentialité :
- prestataire technique de transmission du formulaire ;
- données envoyées par le formulaire ;
- pas de données patrimoniales sensibles demandées dans le formulaire V1.

### Harvest / O2S / MoneyPitch

L’accès client est une redirection externe.
La politique de confidentialité du prestataire externe s’applique dans l’environnement client.

Ne pas intégrer d’API, SSO ou iframe en V1.

## À ne pas faire

- Ne pas demander de montant de patrimoine dans le formulaire V1.
- Ne pas demander de revenus précis dans le formulaire V1.
- Ne pas demander de documents patrimoniaux via le formulaire.
- Ne pas demander de pièces d’identité via le formulaire.
- Ne pas promettre de conseil personnalisé via le formulaire.
- Ne pas confondre durée prospect et durée client.
